Better With Furniture is a furniture mod for Better than Adventure that adds multiple new furniture blocks designed to try and fit with the vanilla version of BTA!

I'm open to suggestions! Looking to keep the mod simple and fitting of the vanilla BTA style and feel!
Feel free to create submods that can be fitted with this mod to add extra furniture that might not fit within the base mod! (For example, a modern furniture submod might be cool!)

Feel free to fork the mod if you'd like, but all I ask is you give the original mod credit, though there's no real requirement for it, but I'd appreciate it!
Also all that is asked is that any forks operate under the same license, this does not apply to submods that don't use the source code of this mod as a base!
